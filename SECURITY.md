# Security Policy

Miu is designed to be a safe and secure desktop companion.

## Security Features
- **No Credentials Stored**: Miu stores no credentials, passwords, or API keys.
- **Spotify Integration**: Spotify integration uses local D-Bus (no API keys required).
- **Data Storage**: All data is stored locally in standard XDG directories (`~/.config/miu/`, `~/.local/share/miu/`, `~/.cache/miu/`).

## Reporting Security Issues
If you find a security vulnerability, please open an issue in this repository or contact the maintainer directly. We appreciate your efforts to keep Miu secure!
